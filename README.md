## 📖 О проекте

**EQUHUB** — масштабируемая цифровая платформа, объединяющая:

- ✅ Социальную сеть
- ✅ Мессенджер
- ✅ Маркетплейс товаров и услуг
- ✅ Раздел вакансий
- ✅ Безопасные сделки
- ✅ AI-помощника
- ✅ Видеосвязь
- ✅ Короткие видео
- ✅ Внутренний кошелёк
- ✅ Систему отзывов и рейтингов
- ✅ Бизнес-инструменты для компаний и продавцов

## 🏗 Архитектура проекта

```
/apps              # Фронтенд приложения
  /mobile          # Flutter мобильное приложение
  /web             # React веб-клиент
  /admin           # Панель администратора

/services          # Бэкенд микросервисы (NestJS)
  /auth            # Сервис авторизации
  /users           # Сервис пользователей
  /feed            # Сервис ленты публикаций
  /chat            # Сервис сообщений
  /marketplace     # Сервис объявлений
  /jobs            # Сервис вакансий
  /wallet          # Сервис кошелька
  /payments        # Платёжный сервис
  /notifications   # Сервис уведомлений
  /search          # Сервис поиска (Elasticsearch)
  /ai              # AI-сервис

/packages          # Общие пакеты
  /ui              # UI компоненты
  /shared          # Общие утилиты
  /config          # Конфигурации

/infrastructure    # Инфраструктура
  /docker          # Docker конфигурации
  /kubernetes      # K8s манифесты
  /terraform       # Terraform скрипты

/docs              # Документация
  /architecture    # Архитектурные диаграммы
  /database        # ER-диаграммы, миграции
  /api             # OpenAPI спецификации
  /design          # Дизайн-система, макеты
```

## 🛠 Технологический стек

### Frontend
- **Flutter** — мобильное приложение
- **React + TypeScript** — веб-клиент и админ-панель

### Backend
- **NestJS + Node.js** — микросервисы
- **REST + GraphQL + WebSocket** — API Gateway

### Базы данных и хранилища
- **PostgreSQL** — основная БД
- **Redis** — кэширование и очереди
- **Elasticsearch** — полнотекстовый поиск
- **MinIO** — объектное хранилище файлов

### Инфраструктура
- **Docker + Docker Compose** — контейнеризация
- **Kubernetes** — оркестрация
- **Nginx** — reverse proxy
- **RabbitMQ** — брокер сообщений
- **CI/CD** — автоматизация развёртывания

## 🚀 Быстрый старт

### Требования
- Node.js >= 18
- Docker >= 20
- Docker Compose >= 2.0

### Установка зависимостей

```bash
# Установка зависимостей для всех сервисов
npm install

# Запуск инфраструктуры через Docker Compose
docker-compose up -d
```

### Запуск в режиме разработки

```bash
# Запуск всех сервисов
npm run dev

# Запуск конкретного сервиса
npm run dev:auth
npm run dev:users
npm run dev:marketplace
```
